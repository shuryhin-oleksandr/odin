1. Read the full source before writing anything.
2. Save the original source in `research/sources/<Title>, <Author>.md` if it isn't there yet.
3. Write the summary to `research/notes/<Title>, <Author>.md` using the template below.

## Template

```markdown
# <Title> — <Author>

Source: [<link to file in research/sources>](<relative path>) (<URL>), published <date>.

## <Section header from the source>
- <Main thought>
- <Main thought>

## Conclusion
- <Main takeaway>
```

## Rules
- Use one header for each section of the source, in the source's order.
- Put the main thoughts under each header as short bullet points in your own words.
