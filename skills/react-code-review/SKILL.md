When frontend maks requests to a backend, frontend should handle errors gracefully - show an error message, not just crashing a front end page.

Code should work on different screen sizes.

## react-hook-form + Zod
Forms should be done with react-hook-form and zod for validation.

## swr or @tanstack/react-query
Use swr or @tanstack/react-query for data fetching and caching.
